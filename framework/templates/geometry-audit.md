# Physical geometry audit

Create when the driver set is chosen, before crossover fitting. This audit supports the agent's fit judgment; the drawing tool does not solve interference.

- Declare one datum and conversions for baffle, whole-speaker and cabinet drawings; state view direction separately from coordinates.
- Draw front, rear and side sections using the occupancy list. For each object record shape, x/depth/z intervals, dimensional source and uncertainty. Bounds screen possible clashes; actual profiles and access settle them.
- Separate wood dimensions, static assembled bounds and moving/service clearance. Read both ends of datasheet depth arrows; distinguish flange, recess, through-cut, installed physical depth and acoustic center.
- Include driver/horn bodies, radiator motion, inner duct clearances, board component/lead height, terminals, insulated wire, straps, spacers, adhesives, supports and sealed service spaces.
- Separate total acoustic duct path from the physical internal protrusion and the wall section. State any round/slot or bent-duct modeling equivalence and tuning verification.
- Detail intentional intersections as real joints (for example half-laps), subtract solid union volume once, and check each fastener against panel edges, supports and wire entries.
- Reconcile gross air, every displacement/reserve and net air; replace reserves when detailing the corresponding hardware rather than counting both. Keep clearances and installation access visible in the drawings.
- After any change, regenerate volume/cut list and rerun the alignment plus fixed network and downstream response. Record the effect before freezing the construction package.
